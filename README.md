# INCIDENT ARCHIVE v0.3.4 — CHEMICAL gritty retune only

ベース：v0.3.3

## この版の方針
- **CHEMICALのみ** を再設計
- **LEAK / SOLAR / REGISTER は変更なし**
- いったん結晶・幾何セルの追求を止め、
  **ざらついた薬品処理 / きつい現像 / 押し感のあるフィルム** に寄せた

## CHEMICALの変更点
- 大きく目立つ多角形は撤去
- ウェットな現像ムラ、漂白、染料の流れ、押したフィルムのような粒状感を追加
- コントラストをやや強め、冷たい色転びと少し暖色の残りを共存
- ざらっとした薬品処理で画がきつくなった感じを狙う

## 変更していないモード
- LEAK
- SOLAR
- REGISTER

## 配置
- ZIP内のファイルを既存ファイルに上書き
- `engines/` フォルダーごとアップロード
- 表示バージョンが `0.3.4` になっていることを確認
