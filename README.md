# INCIDENT ARCHIVE v0.3.3 — CHEMICAL soft retune only

ベース：v0.3.2

## この版の方針
- **CHEMICALのみ** を再調整
- **LEAK / SOLAR / REGISTER は変更なし**
- 多角形ベースの個性は残しつつ、
  不気味さ・汚さを減らし、**漏れ・染み・クールな色変化**を増やした

## CHEMICALの変更点
- 多角形セルによる局所的な色変化は維持
- 暗い残渣・重すぎる境界を弱めた
- 明るい色漏れ、軽い漂白、透明感のあるカラーリフトを追加
- 画面全体の印象を、怖い・濁る方向ではなく、少しスタイリッシュで抜けのある方向へ調整

## 変更していないモード
- LEAK
- SOLAR
- REGISTER

## 配置
- ZIP内のファイルを既存ファイルに上書き
- `engines/` フォルダーごとアップロード
- 表示バージョンが `0.3.3` になっていることを確認

## 確認状況
- JavaScript構文チェック通過
- 他3モードのエンジンファイルは v0.3.2 と同一であることをハッシュで確認
