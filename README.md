# INCIDENT ARCHIVE v0.3.2 — Mode Isolation / Original Comparison

## 変更範囲
- LEAK: エンジンファイルはv0.3.1と完全に同一（無変更）。
- SOLAR / REGISTER: GLSL描画アルゴリズムはv0.3.1と同一。シェーダーだけでなくレシピ生成・uniform設定までそれぞれ専用ファイルへ分離した。
- CHEMICAL: v0.2.9.9の「色の変わる多角形」をベースに復元。セルを細分化し、局所的な色変化を強調、太い輪郭は抑制。
- 入力確認: プレビュー画像を長押し / マウスで押している間は、加工前の画像をWebGLを通さずHTML画像として表示。離すと現在のモードへ戻る。

## 重要な切り分け
過去の出力では複数モードにほぼ同位置の三角形が見えます。しかしSOLAR / REGISTER / LEAKのGLSLコードは幾何学的な三角形を作りません。
入力ファイルに三角形が含まれているなら、各加工エンジンでは除去できません。新設の「プレビューを押して原画像表示」を使って切り分けてください。
原画像が正常なのに処理後だけ同じ三角形が発生するなら、WebGL / 画像デコード / 保存経路を追加調査する必要があります。
「必ず除去できた」という未検証の主張はしません。

## 既存機能
MUTATE, BACK, EDIT, 高解像度PNG, DOWNLOAD PNG, SHARE / SAVE TO PHOTOS, モード別パラメータ保持、UIスタイル、元画像比率は保持。

## GitHub Pages への配置
既存のリポジトリ直下にファイルを上書きし、`engines/` の4ファイルをフォルダごと配置してください。既存の `icons/` は消さないでください。
画面のバージョン `0.3.2` を確認してください。必要に応じてiPhoneのホーム画面アプリを閉じて再起動してください。
