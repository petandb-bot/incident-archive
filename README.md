# INCIDENT ARCHIVE v0.2.9.3 — LEAK再調整（フィルター染まり）

ベース：ユーザー提供 v0.2.9.1 → v0.2.9.2 修正版をさらに更新

## 今回の変更

### LEAK
- 光漏れ主体ではなく、写真の端から入り込む**半透明の色フィルター／染まり**を主役に再設計。
- 鋭い光線、切断面のような直線境界、白い発光コアをさらに抑制。
- LEAK内部で写真が透けて見えるゾーンを作り、ベタ塗りではないフィルター感に調整。
- 赤固定ではなく、`MUTATE`ごとに選ばれるパレット `uC0 / uC1 / uC2` を主色に使用。
- そのため、ミント系・ライラック系・シアン系・アンバー系・シルバー系などへ色相が変化する。

### CHEMICAL
- v0.2.9.2 の修正を維持。
- 中央の縦線を生みやすい不連続な処理は入れていない。

### PNG エクスポート
- v0.2.9.2 の保存安定化を維持。
- WebGL描画内容を一時2Dキャンバスへ固定してからPNG化する方式を継続。

## 維持した内容
- **SOLAR / REGISTER** のシェーダー
- 4モード構成、GUI、各ボタン、AMOUNT / CHANCE / PRESERVE、MUTATE / BACK
- 元画像の縦横比、1800 / 2600 / 3200px の出力選択、iPhone共有・PNG保存処理
- p5.js 1.11.13

## GitHub Pages への配置
1. このフォルダーの `index.html`, `style.css`, `sketch.js`, `sw.js`, `manifest.webmanifest` を既存ファイルに**上書き**。
2. `icons/` ディレクトリは**そのまま残す**。
3. 反映後、Safariで再読み込み。ホーム画面アプリの場合は必要に応じて閉じ直し、再起動、または削除→再追加。
4. ヘッダーに `0.2.9.3` と表示されることを確認。
