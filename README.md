# INCIDENT ARCHIVE v0.3.5 — CHEMICAL cold flash retune only

ベース：v0.3.4

## この版の方針
- **CHEMICALのみ** を再調整
- **LEAK / SOLAR / REGISTER は変更なし**
- 目標は
  1. **もっと夜のフラッシュ写真っぽく**
  2. **もっと冷たくする**

## CHEMICALの変更点
- 直接フラッシュを焚いたような、白いハイライト反応を強化
- 影をやや深くし、夜のスナップ感を増加
- 粗めのフラッシュ粒子感を強化
- 全体の色味をより寒色寄りに調整
- 冷たい銀色・青白いトーンと、少し残る暖色を併存

## 変更していないモード
- LEAK
- SOLAR
- REGISTER

## 配置
- ZIP内のファイルを既存ファイルに上書き
- `engines/` フォルダーごとアップロード
- 表示バージョンが `0.3.5` になっていることを確認
